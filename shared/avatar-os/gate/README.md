# GATE CSE ENGINE

Target: GATE CSE 2027. Decision priority: IIT admission first, PSU second.

## Study loop

For every topic, use `Learn → Retrieve → Solve → Test`.

1. **Learn:** one primary source; build the mechanism first.
2. **Retrieve:** close the source and reconstruct the idea from memory.
3. **Solve:** attempt PYQs/problems without AI or solution access.
4. **Test:** use timed mixed questions and revisit only demonstrated gaps.

## What Katara/Aang should do

- Maintain exactly one `NEXT GATE` action in `../STATE.md`.
- Ask for the learner's attempt before explaining a problem.
- When testing, present one GATE-style question and do not reveal the answer.
- Classify errors by root cause, not merely by subject.
- Put only durable gaps in `ERROR_LOG.md`.
- Use `notes/TEMPLATE.md` for concise topic notes; do not create transcript dumps.

## Diagnostic

Follow `DIAGNOSTIC.md`. The diagnostic chooses the initial subject sequence; it
is not a score prediction or a judgment.
